RLM Harness Evaluation Lab

HarnessBench

A tiny interactive lab for connecting Prime-Agent-style recursive harnesses with Terminal-Bench-style evaluation signals.

Core idea: an agent failure is not always a model failure. Sometimes the harness forgot state, split work badly, used the wrong tool, hit a resource limit, or got misled by a verifier. HarnessBench turns those failures into concrete harness improvements.

Prime-style harness loop task -> state -> subagents -> tools -> eval -> refinement
Main agent Plans, delegates, merges results, decides whether the run is done.
Persistent state Stores files, notes, handles, summaries, and task history outside the prompt.
Subagents Split review, testing, docs, debugging, or search into focused child runs.
Terminal env Runs shell commands, test suites, dependency installs, scripts, and verifiers.
Eval loop Turns failures into typed signals the harness can learn from next time.
